Known limitations

  • kaggle_2023_* rows are from 2023; API/board rows are from Oct 2026. Filter on posted_year when comparing markets over time.
  • skills_enriched = True means the team added skills that were not written in the posting (inferred from title / similar postings). Use skills_enriched == False for strict skill-demand analysis.
  • salary_is_estimate = True means a market benchmark (Paylab, Indeed, BLS ...) was attached, not the posting's own pay. Use only salary_is_estimate == False for pay analysis.
  • Currency conversion uses fixed approximate rates (USD_PER_UNIT in src/clean_utils.py).
  • Jooble/Careerjet descriptions are short API snippets, not full job texts.
  • Role category is a keyword rule on the title (baseline); the ML classifier (WP7) should improve it.
